# RU reachability check package

Этот архив подготовлен без изменения файлов в текущем репозитории и без `worker.js`.

## Что добавлено

В `main.py` добавлена мягкая проверка достижимости host:port из России через Globalping:

```text
RU_CHECK_MODE=soft
GLOBALPING_LOCATION=RU
GLOBALPING_LIMIT=50
```

Проверка выполняется только для финалистов, которые уже прошли Xray real_check.

## Режимы

- `off` — выключено.
- `soft` — RU-доступные узлы выбираются первыми, неизвестные не выкидываются. Рекомендуемый старт.
- `strict` — в подписку попадает только то, что Globalping подтвердил из РФ. Включать после тестов.

## Почему без Globalping token

Без токена используется публичный лимит Globalping. С токеном обычно выше лимиты/стабильнее квоты и меньше риск rate-limit. Для старта на 50 финалистов лучше начать без токена и посмотреть, хватает ли.

## Что не изменено

`worker.js` намеренно исключён из архива.
